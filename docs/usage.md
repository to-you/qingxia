# 轻匣 · Windows 开发测试版

轻匣是一款 Windows 本地效率工具，把剪贴板历史、截图标注、滚动长图和多图拼接收进同一个工作台。
源码运行与 Windows 便携版均由本仓库维护。

## 启动与退出

右键 `启动开发版.ps1`，选择“使用 PowerShell 运行”；或者在仓库目录执行：

```powershell
.\.venv\Scripts\python.exe .\main.py
```

启动后显示剪贴板面板，收起后仍在系统托盘运行。托盘右键 → 退出可完全关闭。
重复启动会提示已有实例，无需反复启动。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+V | 打开 / 收起剪贴板 |
| Ctrl+Alt+S | 截图与标注 |
| Ctrl+Alt+E | 打开已有图片标注 |

快捷键被其他程序占用时会显示通知，也可使用托盘菜单。

点击剪贴板右上角齿轮，或托盘右键 → 设置，打开统一设置面板。
常规页可切换当前用户的开机自启动、手动启动时是否显示剪贴板，并打开数据目录。
全局快捷键页可分别修改剪贴板、截图、打开图片标注三个快捷键；支持互换按键。
剪贴板页可设置自动记录和点击外部收起。修改后点击“应用”，下次启动仍保留。
快捷键重复或被占用时不应用新设置。恢复默认只修改面板中的选项，点击“应用”后才生效。

开机自启动默认关闭。开启后通过当前 Windows 用户的登录启动项运行，不需要管理员权限。
自动启动时只驻留托盘，不弹出剪贴板；手动启动遵循常规页的显示选项。
移动程序目录后，请重新关闭并开启自启动，以更新启动路径。
面板从屏幕底部滑入，重复按快捷键、Esc 或点击面板外部时滑出收起。
点击面板内部以及操作右键菜单不会提前收起。

## 剪贴板

- 自动记录文字、图片与本地文件；识别文本中的链接和十六进制颜色。
- 横向卡片、搜索、分类、收藏、单标签筛选；右键卡片管理。
- 双击卡片或按 Enter，复制并尝试粘贴回唤起前的窗口。Alt+1–9 直接粘贴对应记录。
- 滚轮横向浏览，左右方向键选择记录。Esc 收起。
- 文件记录引用原路径，不备份文件；原文件删除或移动后需重新复制。
- 托盘菜单可暂停记录。历史只保存在本机，未收藏记录最多保留 200 条。
- 程序启动会读取当前剪贴板；退出期间不会记录。

## 截图与标注

- 拖动框选，或单击选择窗口；Esc / 右键取消。选区边缘控制点可调整范围。
- 工具栏最左侧“尺寸”：选择平台模板后锁定构图比例，拖动边缘仍保持比例，保存和复制按所选像素尺寸导出；“自由选区”恢复原始分辨率。
- 矩形、椭圆、箭头、文字、高亮、画笔、步骤序号、马赛克及导入图片贴纸。
- 文字工具：点击截图直接输入，Enter 换行，Ctrl+Enter 或点击空白处完成，Esc 取消本次输入；双击已有文字可原位修改。
- 直接拖动已有标注可调整位置，无需先切换工具；按 Shift 可在已有标注上继续绘制。
- V 选择工具下拖动空白选区可移动选区，Delete 删除选中标注。
- Ctrl+Z / Ctrl+Y 撤销与重做；Ctrl+S 保存图片；Enter 复制并完成。
- 钉图后可拖动位置，滚轮缩放，双击 / Esc 关闭。
- 完成的截图会进入剪贴板历史。自由选区下，导入图片保存时保留原分辨率。
- 多显示器采用每屏独立框选，不支持一个选区跨越多个显示器。

内置常用构图模板（像素）：

| 平台 | 模板 |
| --- | --- |
| 小红书 | 竖图 1080×1440；方图 1080×1080 |
| 抖音 | 竖屏 1080×1920；横屏 1920×1080 |
| 微博 | 方图 1080×1080；竖图 1080×1440 |
| 微信公众号 | 头条封面 900×383；次条封面 500×500 |
| X / 推特 | 横图 1600×900；主页封面 1500×500 |
| Instagram | 竖图 1080×1440；经典竖图 1080×1350；方图 1080×1080；限时动态 1080×1920 |

这些模板用于常见发布场景；也可选择自由选区，按原始分辨率导出。

长截图：框选后点击工具栏的滚动图标，在原窗口向下滚动，滚动过程中连续截取、拼接并实时更新右侧预览，无需停下等待或点击追加。
选区右侧显示长图预览，底部提供标注、保存、取消、复制完成四个按钮。每次保留约三分之一的重叠内容；无法可靠匹配时会暂停追加并提示回滚，不会强行拼接。
页面包含播放中的视频时，已截取区域保留当时的静帧；使用稳定的页面区域或选区周围内容对齐，后续只追加新露出的内容。
长图拼接完成后可继续标注；长图在编辑器中按屏幕比例显示，导出保留实际分辨率。

## 多图拼接

- 剪贴板面板点击“拼图”，或按 Ctrl 单击多选图片后点击“拼图”；图片右键菜单和托盘也有入口。
- 支持导入多张本地图片，以及在编辑器中从剪贴板历史多选添加。
- 内置六种布局：竖向长图、横向拼接、双列网格、三列网格、主图在左、主图在上。
- 左侧可拖动排序，或使用上移、下移、移除按钮；第一张图片作为主图模板中的主图。
- 支持自动尺寸、方图、竖图、竖屏、横图和公众号封面画布；可调整间距、外边距、圆角、背景颜色及透明度。
- “完整显示”保留整张图片；“填满画框”按比例居中裁切。预览随布局实时更新，导出使用完整像素尺寸。
- 成图可以复制到剪贴板、保存为 PNG/JPG，或继续进入截图标注。复制和保存的拼图会进入本地历史。

## 界面与边界

使用轻匣的匣形标识、薄荷绿与暖白配色、卡片分类胶囊和实时预览编辑界面。
品牌标识、标注工具 SVG 与测试画面保存在本项目；通用控件与图标使用已登记的开源依赖。
当前不包含 OCR、录屏或云同步。依赖声明见 `THIRD_PARTY_NOTICES.md`。

当前数据目录可通过托盘“打开数据目录”查看，位于 `%LOCALAPPDATA%\QingXia\data`。启动时自动迁移旧版数据，保留历史、收藏、快捷键和设置。
该目录包含 `history.sqlite3` 和错误日志，退出程序后可自行备份。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m unittest test_tools test_collage -v
.\.venv\Scripts\python.exe verify_desktop.py
```

验证脚本使用临时数据库，结束后恢复原系统剪贴板；会短暂显示测试窗口。
自启动测试使用独立的临时注册表键并在结束时删除，不修改实际的 Windows 登录启动项。
自制验证画面由 `qa_fixtures.py` 绘制，桌面验证截图和结果位于 `artifacts`；运行应用不依赖这些验证文件。
